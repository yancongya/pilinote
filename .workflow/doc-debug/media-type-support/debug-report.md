### 前端实现

**核心组件**:
- `useVideoDownload` Hook: 处理不同媒体类型的下载逻辑
- `FavoritesContent`: 收藏页组件
- `WatchLaterContent`: 稍后再看页组件

**关键逻辑**:
```typescript
// 检测视频类型
if (pages.length === 1) {
  // 单P视频处理
  createSingleTask(video);
} else if (pages.length > 1) {
  // 多P视频处理
  createMultipleTasks(video);
}
```

### 后端实现

**核心服务**:
- `QueueManager`: 统一队列管理器
- `TaskService`: 任务服务，处理任务准备和执行
- `SchedulerService`: 调度器服务，管理系列视频
- `DownloadEngine`: 下载引擎，基于yt-dlp

**数据模型**:
- `Task`: 任务模型，包含media_type、meta等字段
- `Scheduler`: 调度器模型，包含任务列表和管理逻辑
- `Queue`: 队列模型，管理任务队列
