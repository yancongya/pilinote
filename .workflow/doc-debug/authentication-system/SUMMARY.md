## 遇到的问题

### 问题 1: API 服务器状态

**描述**: 初始检查时不确定 API 服务器是否运行

**解决**: 使用 curl 命令验证服务器状态，确认服务器正常运行

### 问题 2: Playwright 测试文件位置

**描述**: 初始测试文件放在 `.workflow` 目录，Playwright 配置指定的测试目录是 `./tests`

**解决**: 将测试文件复制到 `tests/` 目录

### 问题 3: 测试超时设置

**描述**: 尝试设置超时参数时出错（超过 3600 秒限制）

**解决**: 不设置超时参数，使用默认超时

### 问题 4: 端点 404 响应混淆

**描述**: 测试端点存在性时，某些端点返回 404，难以区分是端点不存在还是数据不存在

**解决**: 分析响应内容，FastAPI 的 404 有 `{"detail":"Not Found"}`，业务逻辑的 404 有特定消息如 `{"detail":"账号不存在"}`
