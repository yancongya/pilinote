**关键算法**:
```python
async def _filter_new_videos(self, media_list, source_type):
    """过滤新视频"""
    videos = []
    for video in media_list:
        if await self._is_new_video(video, source_type):
            videos.append(video)
    return videos

async def _is_new_video(self, video, source_type):
    """检查是否为新视频"""
    # 检查数据库中是否存在已完成的任务
    # 检查队列中是否存在未完成的任务
    return not self._task_exists(video.media_id)
```

**去重逻辑**:
- 检查数据库中的已完成任务
- 检查队列中的未完成任务
- 避免重复添加

## 数据流程验证

### 完整扫描流程

```
用户触发扫描
    ↓
API接收请求
    ↓
验证参数（source_type, source_id）
    ↓
获取用户SESSDATA
    ↓
调用ScanService
    ↓
┌─ 获取媒体列表
│  ├─ 收藏夹: get_folder_media_list()
│  └─ 稍后再看: get_watchlater_media_list()
└─ 过滤新视频
   ├─ 检查数据库任务
   ├─ 检查队列任务
   └─ 返回新视频列表
    ↓
批量创建任务
    ↓
保存扫描记录
    ↓
返回结果
    ↓
前端更新UI
```

### 关键数据节点

**输入数据**:
- source_type: favorite/watch_later
- source_id: all 或具体收藏夹ID
- 用户SESSDATA（用于API认证）

**中间数据**:
- media_list: 原始媒体列表
- new_videos: 过滤后的新视频列表
- task_ids: 创建的任务ID列表

**输出数据**:
- total: 总视频数
- new: 新视频数
- added: 实际添加数
- folders: 收藏夹列表
- folder_count: 收藏夹数量
