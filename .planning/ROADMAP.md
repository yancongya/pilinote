# PiliNote AI 笔记功能 Roadmap

## 概述

为 PiliNote 添加 AI 笔记生成功能：媒体库点击已下载视频 → 触发 AI 分析 → 生成 Markdown 笔记 + 思维导图。

## 成功标准

**v1 完成后必须满足：**
- 用户可在媒体库点击视频触发 AI 分析
- 支持 9 种笔记风格切换
- 生成可读的 Markdown 笔记
- 前端展示 Markdown + 思维导图
