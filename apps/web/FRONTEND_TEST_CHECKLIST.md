# PiliNote 前端测试检查清单

## 测试前准备

### 1. 启动服务

**启动API服务**：
```bash
cd apps/api
python3 main.py
```

**启动前端服务**（新终端窗口）：
```bash
cd apps/web
npm run dev
```

### 2. 运行自动化测试脚本

```bash
cd apps/web
./test_frontend.sh
```

## 快速测试命令

```bash
# 1. 查看缓存统计
curl http://localhost:8000/api/cache/stats

# 2. 查看队列状态
curl http://localhost:8000/api/queue/

# 3. 查看任务列表
curl http://localhost:8000/api/queue/tasks

# 4. 查看调度器列表
curl http://localhost:8000/api/queue/schedulers

# 5. 清理过期缓存
curl -X POST http://localhost:8000/api/cache/cleanup

# 6. 清空所有缓存
curl -X POST http://localhost:8000/api/cache/clear

# 7. 测试视频信息API
curl http://localhost:8000/api/media/video/BV1xx411c7mD

# 8. 测试稍后再看API
curl 'http://localhost:8000/api/media/watchlater?sessdata=YOUR_SESSDATA'

# 9. 提交测试任务
curl -X POST http://localhost:8000/api/queue/tasks \
  -H 'Content-Type: application/json' \
  -d '{"media_type":"video","media_id":"BV1xx411c7mD","title":"测试"}'

# 10. 创建测试调度器
curl -X POST http://localhost:8000/api/queue/schedulers \
  -H 'Content-Type: application/json' \
  -d '{"title":"测试","folder":"/tmp/test"}'
```

## 常见问题排查

### 问题1：页面白屏
**检查**：
- 打开浏览器控制台查看错误
- 检查API服务是否运行
- 检查前端服务是否运行

**解决**：
- 重启前端服务
- 清除浏览器缓存

### 问题2：视频加载失败
**检查**：
- 检查SESSDATA是否有效
- 检查网络连接
- 查看API响应

**解决**：
- 重新登录
- 检查代理设置

### 问题3：时间显示NaN
**检查**：
- 检查API返回的时间戳
- 检查formatTime函数

**解决**：
- 已在代码中修复
- 刷新页面验证

### 问题4：下载按钮不工作
**检查**：
- 检查是否已登录
- 检查视频ID是否有效
- 查看控制台错误

**解决**：
- 重新登录
- 检查API响应
