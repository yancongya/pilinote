PiliNote Docs launcher binaries are placed here by platform.

Expected paths:

- `apps/desktop/resources/docs/mac/pilinote-docs-macos`
- `apps/desktop/resources/docs/win/pilinote-docs.exe`
- `apps/desktop/resources/docs/linux/pilinote-docs`

These are optional companion binaries for launching built docs (`apps/docs/.vitepress/dist`)
as a local static site.
