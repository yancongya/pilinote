# 元数据收集与标准

- 收集目标
  - 标题、封面、时长、发布时间、观看量、弹幕、评论、点赞、投币、收藏、分享等统计指标
- 数据来源
  - Watch Later 与 Favorites 的后端 API 返回字段 + Bilibili 原生 API 统计字段
- 处理流程
  - 后端统一封装一个数据模型 CardData，前端直接使用该模型字段
  - 字段归一化：不同来源字段映射到同一字段名，必要时进行单位换算
- 元数据更新策略
  - 数据刷新周期：如 5-15 分钟内缓存刷新或按请求触发刷新
  - 对应缓存策略与版本控制
- 错误处理
  - 缺失字段设默认值，必要字段严格校验，异常字段日志记录
