# 下载引擎方案

## 核心引擎
- **yt-dlp**: 统一下载引擎
  - 支持B站1000+站点
  - 自动处理认证
  - 支持多画质
  - 自动下载字幕/弹幕

## 任务队列
- **Celery + Redis**
  - 异步任务处理
  - 队列管理
  - 任务状态跟踪
  - 失败重试

## 下载流程
1. 解析视频信息
2. 检查是否已下载
3. 添加到队列
4. 后台下载
5. 实时进度推送
6. 自动处理字幕/弹幕
7. 保存元数据

## 画质支持
- 1080P+ (需要登录)
- 1080P
- 720P
- 480P
