# MediaListTopBar 设计规范

## 背景

收藏页、稍后再看页、历史记录页已经统一成同一套 `MediaListShell` / `MediaListState` 的历史型视频列表结构，但当前顶部导航和筛选组件仍然分散在各页内部。

现状问题：
- 顶部区域在三个页面中的布局不完全一致
- 滚动时顶部控制条不会统一吸顶
- 左右边距和控制区宽度表现不一致
- 收藏页的列表头、筛选条、刷新操作仍然有局部样式分叉

目标是把这三页的顶部区域统一成一个可复用的页面级顶部栏组件，让它在页面滚动时始终悬浮在内容上方，并且横向撑满当前内容区。

## 目标

- 三个页面共用同一套顶部结构和交互规则
- 顶部导航和筛选条在页面滚动时始终保持可见
- 顶部区域横向铺满内容区左右边缘
- 保持现有列表内容区和懒加载逻辑不变
- 为后续更多“历史型视频列表”页面留出扩展接口

## 非目标

- 不重做视频卡片布局
- 不修改收藏页、稍后再看页、历史记录页的数据源逻辑
- 不改变后端 API 协议
- 不重构 `MediaListShell` 的状态层实现

## 设计方案

### 1. 新增 `MediaListTopBar`

新增一个页面级顶部壳层组件，负责承载：
- 页面标题
- 数量统计
- 返回 / 刷新 / 额外动作按钮
- 搜索框、排序器、方向切换
- 其他页面级筛选项

这个组件只管布局和 sticky 行为，不负责业务数据获取。

### 2. 布局结构

顶部栏分为两行：
- 第一行：标题区 + 统计区 + 右侧动作区
- 第二行：筛选区 / 搜索区 / 排序区

如果某个页面动作较少，可以收敛成单行，但组件内部仍保持两行能力，方便收藏页这类操作较多的页面扩展。

### 3. 吸顶策略

`MediaListTopBar` 默认启用 sticky：
- `position: sticky`
- `top: 0`
- `z-index` 高于列表内容区
- 使用页面背景色覆盖下方内容，避免滚动时透出

吸顶范围以当前页面滚动容器为准，而不是整个浏览器窗口之外的额外层级。

### 4. 横向撑满

顶部栏宽度应与 `MediaListShell` 的内容区一致：
- 左右 padding 与列表主体保持一致
- 不再让筛选条只占一小段局部宽度
- 在桌面端尽量使用 `width: 100%`
- 在移动端保持安全边距和可点击区域

### 5. 页面配置方式

三个页面通过配置对象接入同一顶部壳层：
- `FavoritesContent`
- `WatchLaterContent`
- `HistoryContent`

每个页面只提供：
- 标题
- 统计文本
- 搜索框状态
- 排序选项
- 吸顶区右侧按钮
- 是否显示返回按钮

## 组件职责

### `MediaListShell`

负责页面主体壳层、加载态、空态和错误态，不承载具体顶部栏布局。

### `MediaListTopBar`

负责顶部吸顶区域和控制条布局。

### `VideoListControls`

继续负责搜索、排序、方向切换、刷新等具体控件，但不再单独定义页面布局。

## 交互规范

- 页面滚动时顶部栏始终可见
- 顶部栏不覆盖内容交互区域
- 筛选项变化后保持顶部栏位置稳定
- 搜索和排序控件在桌面端横向排列，在窄屏下自动换行
- 收藏页的返回收藏夹列表按钮和刷新按钮保留在顶部栏中

## 响应式规则

- 桌面端：标题区、统计区、按钮区和筛选区尽量一屏内展示
- 平板端：允许两行布局
- 手机端：标题区与筛选区纵向堆叠，避免控件过密

## 迁移范围

需要迁移的文件：
- `apps/web/src/pages/components/FavoritesContent.tsx`
- `apps/web/src/pages/components/WatchLaterContent.tsx`
- `apps/web/src/pages/components/HistoryContent.tsx`

- `apps/web/src/components/VideoListControls.tsx`
- `apps/web/src/components/VideoListControls.css`

## 验收标准

- 三个页面的顶部导航和筛选条均使用同一套顶部壳层
- 页面滚动时顶部栏始终吸顶
- 顶部栏左右边缘与内容区一致
- 收藏页、稍后再看页、历史记录页的顶部视觉一致
- 不影响列表骨架、加载更多和空状态

## 风险

- `position: sticky` 可能受外层滚动容器影响，需要确认实际滚动层
- 收藏页顶部动作较多，可能需要两行布局而不是单行
- 移动端换行后需要防止标题和筛选项过于拥挤
