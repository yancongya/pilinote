# PiliNote 交互反馈规范

## 概述

本文档定义了PiliNote应用的交互反馈规范，确保所有可交互元素提供一致、清晰的用户反馈。

## 交互状态

### 1. 悬停状态（Hover）

**适用元素**：所有可交互元素（按钮、链接、卡片、表单控件等）

**实现规范**：
```css
.element:hover:not(:disabled) {
  /* 视觉反馈 */
  transform: translateY(-1px);
  box-shadow: var(--shadow-md);
  background: var(--color-bg-tertiary);
  color: var(--color-primary-600);
}
```

**标准反馈**：
- 按钮：轻微上移 + 阴影增强 + 颜色变化
- 链接：颜色加深 + 下划线
- 卡片：阴影增强 + 轻微上移
- 表单控件：边框颜色变化

### 2. 点击状态（Active）

**适用元素**：所有可点击元素

**实现规范**：
```css
.element:active:not(:disabled) {
  /* 点击反馈 */
  transform: translateY(0);
  background: var(--color-primary-700);
}
```

**标准反馈**：
- 按钮：位置复原 + 颜色加深
- 卡片：位置复原 + 轻微缩放
- 其他元素：颜色变化或位置变化

### 3. 焦点状态（Focus）

**适用元素**：所有可通过键盘导航的元素

**实现规范**：
```css
.element:focus {
  outline: none;
  border-color: var(--color-primary-600);
  box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.1);
}
```

**标准反馈**：
- 边框颜色变为主色调
- 外部添加3px的半透明阴影
- 确保键盘用户能看到焦点位置

### 4. 禁用状态（Disabled）

**适用元素**：所有可交互元素

**实现规范**：
```css
.element:disabled {
  opacity: 0.5;
  cursor: not-allowed;
  transform: none !important;
}
```

**标准反馈**：
- 透明度降低至50%
- 光标变为禁用状态
- 移除所有交互效果
- 文字颜色变灰

### 5. 加载状态（Loading）

**适用元素**：按钮、表单提交、异步操作

**实现规范**：
```css
.element.loading {
  position: relative;
  pointer-events: none;
  opacity: 0.8;
}

.element.loading::after {
  content: '';
  position: absolute;
  width: 16px;
  height: 16px;
  border: 2px solid rgba(255, 255, 255, 0.3);
  border-top-color: white;
  border-radius: 50%;
  animation: spin 0.6s linear infinite;
}

@keyframes spin {
  to { transform: rotate(360deg); }
}
```

**标准反馈**：
- 显示旋转的加载图标
- 禁用点击
- 透明度略微降低
- 文本显示"加载中..."

### 6. 错误状态（Error）

**适用元素**：表单控件、输入验证

**实现规范**：
```css
.element.error {
  border-color: var(--color-error-500);
}

.element.error:focus {
  box-shadow: 0 0 0 3px rgba(239, 68, 68, 0.1);
}
```

**标准反馈**：
- 边框颜色变为红色
- 焦点阴影也变为红色
- 显示错误提示文字

### 7. 成功状态（Success）

**适用元素**：表单提交、操作完成

**实现规范**：
```css
.element.success {
  border-color: var(--color-success-600);
  color: var(--color-success-600);
}
```

**标准反馈**：
- 边框颜色变为绿色
- 文字颜色也变为绿色
- 可选：显示成功图标

## 过渡动画

### 标准过渡

```css
.element {
  transition: all 0.2s ease;
}
```

### 快速过渡

```css
.element {
  transition: all 0.15s ease;
}
```

### 慢速过渡

```css
.element {
  transition: all 0.3s ease;
}
```

## 特殊交互反馈

### 长按反馈
- 适用：移动端长按操作
- 实现：连续震动 + 视觉反馈
- 时长：500ms触发

### 拖拽反馈
- 适用：可拖拽元素
- 实现：透明度变化 + 拖拽阴影
- 释放：动画回到原位

### 手势反馈
- 适用：触摸手势操作
- 实现：实时视觉反馈 + 震动
- 手势：滑动、缩放、旋转

## 无障碍要求

### 键盘导航
- 所有交互元素可通过Tab键访问
- 焦点顺序符合逻辑
- 焦点状态清晰可见

### 屏幕阅读器
- 按钮有aria-label
- 表单有关联的label
- 状态变化有aria-live

### 颜色对比
- 文字与背景对比度≥4.5:1
- 图标与背景对比度≥3:1
- 错误信息使用颜色+图标

## 性能考虑

### 动画性能
- 使用transform和opacity进行动画
- 避免在悬停时改变宽高
- 使用will-change优化复杂动画

### 响应时间
- 悬停反馈：<50ms
- 点击反馈：<100ms
- 页面加载：<1s

### 资源优化
- 使用CSS动画代替JS动画
- 避免过多的DOM操作
- 合理使用节流和防抖
