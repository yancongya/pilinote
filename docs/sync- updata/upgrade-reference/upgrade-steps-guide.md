# PiliNote 自动下载功能升级指南（阶段性前后端同步版）

本版本将升级拆分为六个阶段，并在每个阶段明确列出前端改动、后端改动、测试要点和验收标准。核心原则：前后端同频升级、每阶段具备可验证的端对端场景。

## 阶段 1：基础数据存储与设置界面
- 前端改动：新增 Auto Download 设置面板，显示启用、触发方式(Interval/Cron)、扫描间隔、Cron表达式、并发限制(视频/分页)等字段，提供保存按钮。
- 后端改动：新增 VideoSourceScan 模型、GET/POST /api/auto-download/config，提供默认配置与持久化入口。
- 测试要点：读取默认配置、修改配置并验证持久化、创建测试扫描记录表。
- 验收标准：前端显示/保存成功，后端 API 正常工作，数据库表创建完成。

---

Phase 2：扫描触发与结果展示
- 前端改动：在下载页新增“触发扫描”按钮、显示扫描状态、展示视频列表。
- 后端改动：实现 VideoSourceScanner，提供 /api/auto-download/scan-records 与 /api/auto-download/scan/trigger。
- 测试要点：触发扫描后返回视频列表，前端能更新显示。
- 验收标准：后端能触发扫描，前端能看到结果。

---

Phase 3：自动下载队列落地与显示
- 前端改动：新增队列视图，显示待下载任务。
- 后端改动：实现 AutoDownloadService.add_videos_to_queue，将扫描结果写入队列。
- 测试要点：扫描后队列中出现新任务，前端能渲染。
- 验收标准：队列可写入、前端可观察到队列变化。

---

Phase 4：配置持久化与界面扩展
- 前端改动：扩展配置字段并实现保存。
- 后端改动：实现持久化存储，GET/POST /config 持久化。
- 测试要点：修改并持久化，重启后仍然可用。
- 验收标准：持久化生效，前端显示持久化后的值。

---

Phase 5：定时任务集成
- 后端改动：接入调度器，定时触发扫描与下载。
- 前端改动：展示下次执行时间与状态。
- 测试要点：定时任务触发，日志与数据库更新。
- 验收标准：定时任务稳定运行，前端可观测到状态。

---

Phase 6：高级筛选与重试策略
- 后端改动：实现筛选规则，集成进队列落地，扩展重试配置。
- 前端改动：UI 中增设筛选规则配置。
- 测试要点：筛选规则生效、日志记录筛选原因、重试策略生效。
- 验收标准：符合条件的视频才进入队列，前端可保存筛选规则。

---

升级后验证流程
- 按阶段执行上述测试要点，逐步验证端到端流程。
- 每阶段完成后执行回归测试以确保前后端 API 版本一致。
