# PiliNote 项目概述

## 项目定位

PiliNote 是一个功能强大的 **Bilibili 视频下载管理器**，采用现代化的全栈架构设计，为用户提供高效、稳定的视频下载和管理体验。项目基于 Monorepo 结构，整合了前端 React 应用和后端 FastAPI 服务，实现了从视频解析、下载到管理的完整工作流。

## 核心功能

### 1. 视频下载管理
- **多格式支持**：支持 Bilibili 视频、番剧、课程等多种媒体类型
- **智能队列系统**：四级队列架构（backlog → pending → doing → complete）确保下载有序进行
- **调度器管理**：支持多P视频批量下载，统一调度管理
- **并发控制**：基于信号量的并发控制，支持最多3个并发下载任务

### 2. 媒体管理
- **收藏夹管理**：自动扫描收藏夹，识别新视频
- **稍后再看**：支持稍后再看列表管理和批量下载
- **NFO文件生成**：自动生成包含完整元数据的NFO文件
- **封面和头像下载**：自动下载视频封面和UP主头像

### 3. 用户认证
- **多账号支持**：支持多个B站账号管理
- **多种登录方式**：SESSDATA、二维码、手机验证码登录
- **自动刷新**：支持登录凭证自动刷新和过期处理

### 4. 实时通信
- **WebSocket通信**：实时更新下载进度和状态
- **事件驱动架构**：基于事件的系统设计，高效处理状态变化
- **多客户端支持**：支持多个浏览器同时连接

### 5. 自动化功能
- **自动扫描**：定时扫描收藏夹和稍后再看
- **自动下载**：支持自动下载新发现的视频
- **任务调度**：支持定时任务和批量操作

## 目标用户

### 主要用户
- **视频收藏者**：需要批量下载和管理B站视频的用户
- **内容创作者**：需要备份和整理自己或他人视频的用户
- **教育工作者**：需要下载教学视频进行离线学习的用户

### 使用场景
- **个人备份**：备份收藏夹和稍后再看的视频

- **批量下载**：批量下载系列视频或收藏夹视频

## 技术亮点

### 1. 四级队列系统
```python
# 队列状态流转
BACKLOG → PENDING → DOING → COMPLETED
  ↓         ↓        ↓         ↓
待处理   等待中    执行中    已完成
```

### 2. WebSocket 实时通信
- 任务状态实时更新
- 进度条实时显示
- 多客户端同步

### 3. 事件驱动架构
```python
# 事件类型
- taskCreated: 新任务创建
- taskUpdated: 任务状态更新
- progress: 进度更新
- schedulerUpdated: 调度器更新
- queueUpdated: 队列更新
```

### 4. NFO 文件生成
- 完整的视频元数据
- B站统计数据
- 互动评分计算
