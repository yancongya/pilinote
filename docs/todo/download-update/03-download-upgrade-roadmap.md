# 下载系统升级路线图

## 概述

本文档详细说明了 PiliNote 下载系统的整体升级路线图，包括所有阶段、任务、依赖关系和时间规划。

## 升级目标

### 性能目标
- 下载速度提升 30-50%
- 支持 8-16 并发连接
- 降低服务器负载 20-30%

### 用户体验目标
- 实时显示下载进度
- 无需刷新页面
- 更流畅的交互体验
- 更好的错误提示

### 技术目标
- 零风险升级（完全向后兼容）
- 可配置性（用户可选择）
- 自动降级（失败时回退）
- 模块化设计（易于维护）

## 升级阶段划分

### Phase 0: 当前状态 ✅

**状态**: 已完成  
**时间**: 2026-03-31 之前

**功能列表**:
- ✅ 临时路径下载
- ✅ 自动清理功能
- ✅ 保留失败任务
- ✅ NFO 元数据下载
- ✅ 封面和头像下载
- ✅ 字幕下载
- ✅ 自定义工具路径

**技术栈**:
- yt-dlp 内置下载器
- 前端轮询获取进度
- SQLite 数据库

## 测试策略

### 单元测试
- 每个功能模块都要有单元测试
- 测试覆盖率要求 80%+
- 使用 pytest 框架

### 集成测试
- 测试各模块间的集成
- 测试 API 端点
- 测试 WebSocket 连接

### 性能测试
- 下载速度测试
- 并发下载测试
- 资源占用测试

### 兼容性测试

### 回归测试
