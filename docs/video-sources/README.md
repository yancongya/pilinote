## 支持的链接格式

| 类型 | 示例 |
|------|------|
| BV号 | `BV1xx411c7mD` |
| AV号 | `av12345678` |
| 番剧 | `ep123456`, `ss123456` |
| 音乐 | `au123456` |
| 短链接 | `b23.tv/xxxxxx` |
| 用户空间 | `space.bilibili.com/12345678/video` |
