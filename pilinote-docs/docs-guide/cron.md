# Cron 自动化（扫描 -> 入队 -> 下载）

如果你是重度收藏用户，cron 才是“堆积变可复习”的关键：让扫描与入队自动发生，你只需要定期复盘。

## Cron 适合做什么

- 定时扫描收藏夹/稍后再看/历史/订阅
- 自动把新增条目加入下载队列
- 避免你“想起来才处理”，结果永远堆着

## 频率建议

不建议太激进：

- 太频繁：更容易触发风控、也更容易重复入队
- 太稀疏：新增内容积压，复盘延迟变大

一个相对稳妥的起步：

- 每 4-12 小时一次（根据你的使用强度调整）

## 去重与并发（两个必须注意的坑）

- 去重：同一个 BV/分P 不应重复入队
- 并发：cron 触发时，如果上一次任务还在跑，应避免叠加开新一轮

## 夜间策略（建议）

如果你在意网络或设备噪音：

- 夜间降低并发与限速
- 或只做“扫描入队”，白天再下载
