# 排错与FAQ

这页的目标是：让你遇到问题时能快速定位“是登录/是下载器/是路径/是风控/是AI”。

## 一句话诊断（先做这三步）

1. 手动解析一个 BV（最短链路）
2. 看日志是否有明确报错（路径/权限/下载器缺失）
3. 检查 cookie 是否有效（账号状态）

## 常见问题

### 1) 页面能打开，但列表为空

优先排查：

- 登录态是否失效
- 是否触发风控（请求过频）
- 该接口是否依赖特定 cookie 字段

### 2) 下载失败或卡住

优先排查：

- `aria2c/ffmpeg` 路径配置
- 目标下载目录权限/磁盘空间
- 并发/限速是否过激

### 3) AI 失败或输出很差

优先排查：

- endpoint / key / model 是否正确
- 输入是否过长导致截断
- prompt 是否过于自由导致结构不稳定

## 你应该把哪些信息贴出来（方便排查）

- 复现步骤（点了什么）
- 相关日志片段（去掉隐私信息）
- 你当前的并发/频率配置（尤其是 cron）
