# 路径与存储

这部分决定你后续是否“能迁移、能备份、能复盘”。建议尽早配置好。

## 你需要关心哪些路径

常见路径项：

- 数据库路径：保存账号、队列、设置等
- 下载路径：视频与产物落盘目录
- 日志路径：排错第一现场
- 临时目录：下载/转码/中间文件
- 下载器路径：例如 `aria2c`、`ffmpeg` 等 sidecar 工具

## 推荐目录结构（示例）

把所有东西放在一个“可整体搬走”的根目录下最省心：

- `data/`：数据库
- `downloads/`：视频与 sidecar 产物
- `logs/`：日志
- `temp/`：临时文件

## 迁移与备份

迁移的关键不是“复制某个文件”，而是“保持路径一致性”：

- 若下载目录改变，确保媒体库/索引能重新指向新路径
- 若数据库移动，先备份再改路径

建议把备份策略做成两层：

- 本地定期快照（例如 Time Machine）
- NAS / 云盘同步（避免本机损坏）
