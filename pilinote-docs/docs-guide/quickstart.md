# 快速开始（推荐：一键脚本）

目标：用最少步骤跑起来，并完成一次“入队 -> 下载落盘 -> 生成产物”。

## 1. 启动

优先使用仓库根目录的一键启动脚本（`.command` / `.sh`）。脚本通常会做这些事：

- 启动后端（FastAPI）
- 启动前端（Vite）
- 打开或输出访问地址

如果脚本输出了 URL，直接用浏览器打开即可。

## 2. 检查点（确认启动成功）

- 页面能打开且没有白屏
- 能看到“视频源 / 入队 / 下载 / sidecar / Prompt / AI / 回跳”等流程入口
- 后端健康检查接口能返回成功（如果你知道对应地址）

## 3. 做一次最小闭环

1. 选择一个视频源（或粘贴一个 BV/链接）
2. 点击“解析并入队”
3. 观察下载队列状态变化
4. 下载完成后确认本地目录出现视频与 sidecar 产物（字幕、NFO、截图、笔记等）

接下来建议立刻看：

- [登录与账号](./login.md)（避免后续扫描/下载因为登录态失效卡住）
- [路径与存储](./paths.md)（把数据、下载、日志的目录固定下来，方便迁移和备份）
