# 下载与落盘

目标：把视频稳定保存到本地，并生成可复盘的 sidecar 产物。

## 队列模型（你可以这样理解）

- 入队：把一个条目变成可执行任务
- 调度：控制并发、限速、重试
- 落盘：视频/字幕/元数据写到本地
- 产物：把“视频”变成“可复习资料”

## 常见可配置项

- 并发：同时下载多少个任务
- 限速：避免触发风控/影响网络
- 重试：失败是否自动重试、间隔多久
- 分P：合集/分P如何处理（按实际实现）

## 产物清单（常见）

根据你启用的功能不同，落盘产物可能包括：

- 视频文件（mp4/flv 等）
- 字幕（srt/vtt 等）
- 评论区（json/txt）
- 简介信息（json/txt）
- NFO 元数据（便于媒体库/刮削）
- 截图（用于复盘与定位）
- AI 笔记（md/json）
- 回跳索引（章节/时间戳）

## 排错：下载失败最常见三类原因

1. 下载器/ffmpeg 路径配置错误
2. 登录态失效或触发风控
3. 目标路径无权限/磁盘不足
