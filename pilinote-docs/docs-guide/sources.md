# 视频源与入队

PiliNote 的思路是：把“堆积”变成“队列”。你选择视频源，解析增量内容入队，然后由队列驱动下载与产物生成。

## 支持的视频源（常见）

- 收藏夹（多文件夹）
- 稍后再看
- 观看历史
- 订阅/追更（按项目实际实现）
- 手动解析：粘贴 BV/URL

## 手动解析（排错利器）

当你不确定登录态、风控、下载器是否正常时，先用“手动解析单个 BV”：

- 成功：说明最短链路 OK
- 失败：优先排查下载器路径、cookie、网络

## 增量扫描与去重

增量扫描一般会做这些事：

- 记录已处理的条目（避免重复入队）
- 只把新增/更新内容加入队列

如果你发现重复入队：

- 优先检查：去重键（BV/av + 分P + 时间）是否一致
- 检查 cron 频率是否过高，导致“上一次未完成下一次又开始”
