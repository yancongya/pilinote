# PiliNote 局域网访问快速指南

## 一键启动局域网服务

```bash
./start-lan.sh
```

## 访问地址

启动后，脚本会显示你的局域网 IP 地址，例如：
```
本机 IP: 192.168.31.70
前端访问地址: http://192.168.31.70:5173
```

### 从其他设备访问

**电脑访问：**
- 打开浏览器，访问：`http://192.168.31.70:5173`

**手机访问：**
- 确保手机和电脑连接同一个 Wi-Fi
- 打开浏览器，访问：`http://192.168.31.70:5173`

**平板访问：**
- 同上，访问：`http://192.168.31.70:5173`

## 停止服务

```bash
./stop-lan.sh
```

## 注意事项

1. **所有设备必须连接同一个 Wi-Fi 网络**
2. **不要同时从多个设备进行下载操作**
3. **确保防火墙允许端口 5173 和 8000 的入站连接**
